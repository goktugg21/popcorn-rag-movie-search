# Popcorn not included

Popcorn not included is a modern movie discovery application built with React, Vite, and TailwindCSS. Browse, search, and explore your favorite movies with a beautiful and responsive interface. This project includes a structured project layout with separate folders for pages, components, hooks, and utilities.

## Project Structure

```
src/
├── components/    # Reusable UI components
├── pages/         # Page components
├── hooks/         # Custom React hooks
├── utils/         # Utility functions
├── assets/        # Static assets like images
├── App.jsx        # Main application component
└── main.jsx       # Entry point
```

## Features

- ⚡️ **Vite** - Lightning fast development and build
- 🎨 **TailwindCSS** - Utility-first CSS framework
- 📁 **Organized Structure** - Clean separation of concerns
- 🧩 **Component Library** - Basic reusable components
- 🪝 **Custom Hooks** - Example hooks for common functionalities

## Getting Started

### Prerequisites

- Node.js (version 16.0.0 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn
   ```

### Development

To start the development server:

```bash
npm run dev
# or
yarn dev
```

### Building for Production

To build the project for production:

```bash
npm run build
# or
yarn build
```

### Preview Production Build

To preview the production build locally:

```bash
npm run preview
# or
yarn preview
```

## Available Components

- **Header**: Main navigation header
- **Footer**: Page footer with copyright information
- **Button**: Customizable button with different variants (primary, secondary, success, danger)

## Custom Hooks

- **useWindowSize**: Hook to track window dimensions

## Utility Functions

- **formatDate**: Format JavaScript date objects
- **truncateText**: Truncate long text with ellipsis
